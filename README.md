# PrankCall

მარტივი, ქართულენოვანი ვებ-დემო მეგობრული ზარისა და SMS-ის მოსამზადებლად.

## გამოყენება

გახსენით `index.html` ბრაუზერში, შეიყვანეთ ნომერი ქვეყნის კოდით და სურვილისამებრ დაწერეთ შეტყობინება. **დარეკვა** ხსნის მოწყობილობის სატელეფონო აპს, ხოლო **Messages-ის გახსნა** — შეტყობინებების აპს წინასწარ შევსებული ტექსტით, თუ მოწყობილობა ამას მხარს უჭერს. გაგზავნა/ზარი მომხმარებელმა თავად უნდა დაადასტუროს.

- აპი არ აგზავნის ზარებს ან SMS-ებს ავტომატურად და არ აყალბებს გამომგზავნის ნომერს.
- გამოიყენეთ მხოლოდ მეგობრებთან და მათი თანხმობით; არ გამოიყენოთ მუქარის, შევიწროების ან თაღლითობისთვის.
- ნომერი და ტექსტი სერვერზე არ იგზავნება.

ზოგიერთ ბრაუზერში ბმულების მუშაობა დამოკიდებულია მოწყობილობისა და ნაგულისხმე dialer/Messages հավելվածის тохиргоებზე։
